- One live desktop browser sample (1003 CSS pixels wide, unthrottled, environment network): TTFB 1,364 ms; FCP 3,080 ms; LCP 3,532 ms; load event 4,686 ms. Observed resources: about 831 KB transfer, including 325 KB scripts and 445 KB fonts. This is a diagnostic sample, not a Lighthouse score or a field percentile.
- A live mobile repeat showed LCP 2,120 ms; buffered layout-shift entries involved font/layout changes and the rotating hero word/cursor. Raw sums over the extended session are not reported as standardized CLS.
- A local mobile production sample (433×937 CSS pixels as measured by browser, unthrottled): TTFB 42 ms, LCP 796 ms, load 1,820 ms; maximum CLS session window 0.067. This shows the checked local page functioning; local and live timings have different environment, viewport and cache conditions and are not a controlled before/after comparison.
- PageSpeed Insights API returned HTTP 429; no independent Lighthouse score or CrUX field result obtained. INP was not validated. Do not call the site exceptional or Core Web Vitals passing on this evidence.
- Practical improvements: critical hero fonts discovered earlier, fewer eager noncritical font preloads, deferred founder SVGs, static work/blog pages instead of request-time rendering. No claim of a measured live speedup before release.

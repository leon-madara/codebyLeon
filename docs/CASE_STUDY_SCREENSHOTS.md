# Case-study screenshot provenance

The local Work articles now contain the project screenshots preserved in the original React/Vite case-study source. The old links to `codebyleon.com/work/...` were removed from both the article headers and footers. The local Work routes are the case studies in this version.

Source revision: `ad9998a1cad2b89f42438bc5dd98cad5bbc56bbf` (read from local `main`; no branch switch or main edit).

Source pages: `src/pages/LegitLogisticsCaseStudyPage.tsx`, `src/pages/DelivahDispatchCaseStudyPage.tsx`, and `src/pages/KossyLangatCaseStudyPage.tsx` at that revision. These pages reference the imported files directly.

`case-study-screenshot-sources.json` records source paths, imported paths, SHA-256 hashes, panel placements and captions. Imported PNGs are byte-for-byte copies, with no cropping or retouching. Each figure selects the supplied mobile capture below 768px. The screenshots are preserved project captures, not a claim of the applications' current live state.

Each chapter now starts with a short introduction. Figures follow the relevant section's explanatory paragraph, rather than preceding the whole narrative. The manifest records that section and introduction. A screenshot label sits above the image so visitors can distinguish captured interfaces from interactive page controls.

The header strips describe project capabilities. Unverified timing, loss-prevention, financial, workforce and safety outcomes were removed from those strips and related repeated numerical claims. These pages do not establish measured project results; screenshot provenance does not validate the remaining implementation examples.

Legit Logistics' preserved dashboard capture contains a visible delivery-loading error and was excluded. Its customer order-lookup capture is used instead, without retouching. Its driver and tracking captures show demo/sample workflows and are captioned accordingly. Delivah's upload screenshot shows the carrier submission step, not a staff review dashboard. Kossy's screenshots show the website itself, not evidence for the engineering outcomes described in its copy.

The old public case-study URLs could not be retrieved by the web tool during this import; current production parity was not established. Existing case-study prose and code examples were retained outside this image/link change.
